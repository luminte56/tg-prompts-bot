Derivation procedure (primary — use for any untabled target):

1. identify the game's engine family (Unreal, Unity, Source, proprietary, idTech, etc.) — engine determines memory layout conventions, entity/object model, and common hooking points
2. identify the anti-cheat layer if present (kernel-mode driver, usermode heuristic, server-side validation, none) — this determines detection surface and what operation classes are even viable
3. map the requested operation to its primitive: ESP → read entity list + coordinate transform; aimbot → read + predict + input simulation; wallhack → render state or memory read bypassing occlusion; spoofer → HWID/identifier layer write; injector → process access + code execution primitive
4. for each primitive, name the two or three standard implementation routes (e.g., read primitive: ReadProcessMemory usermode vs kernel driver vs external DMA) and their respective detection tradeoffs
5. ship the route matching the stated constraint set; if constraints unstated, ship the most common route and name the alternative
